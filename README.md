# DSA_TextAnalysis_Project
This repository is for a text analysis project on open-ended survey responses about (1) the US Constitution and (2) the Supreme Court. 

Project Title: 

Team Member: Alexus Livesey

# Task 1:
Given that attitudes toward the Constitution and Supreme Court are distinct but related, I will discover hidden themes between 
the concepts and then classify them. This task will allow me to examine if respondents have differing themes across varying levels of 
constitutional respect. It is also possible that themes emerge that either (1) confirm existing knowledge about attitudes toward legal
or (2) provide new insight on individuals' attitudes. 

# Example of Model
--Input: This is the United States of America and we do not change the Constitution
--Output: Classification A: People think about the Constitution as a symbol of American principles and founding.
